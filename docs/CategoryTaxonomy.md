# 分类体系（草案 v1）

分类表只有三个顶层：**内容拓展**、**非内容拓展**、**系列**。
分类路径用 `/` 分层，例如 `内容拓展/种族/NewRatkin`。

---

## 1. 内容拓展

给游戏**增加可玩内容**的模组。判断标准：装了以后游戏里多出东西——种族、物品、建筑、植物、事件、能力、地图等。

### 1.1 种族

包含：

- HAR 种族（`AlienRace.ThingDef_AlienRace`）
- 基因/异种人种族（Xenotype，有独立种族定位的那种）
- 二次元动物类模组（兽人、兽娘一类，按种族处理）

内部结构：**一个种族一个文件夹，装这个种族的全部模组**。

```
内容拓展/种族/NewRatkin
    NewRatkin                 ← 种族本体
    NewRatkin_zh              ← 汉化
    NewRatkin Apparel         ← 服装
    Ratkin Facial Animation   ← 表情
    Ratkin CE Patch           ← 兼容补丁
```

- 翻译包、补丁、服装、发型、表情，只要是**只服务这一个种族**，都放该种族文件夹
- 种族文件夹用种族英文名，和模组本体名一致

**同时属于多个种族的模组**，单独放一个合并文件夹，用 `and` 连接：

```
内容拓展/种族/NewRatkin and Kurin
    Ratkin and Kurin Shared Apparel
```

- 超过两个种族时，末尾用省略号：`NewRatkin and Kurin and……`
- 判断依据：模组本身面向多个种族（共用服装、共用补丁等），而不是"它同时改了 A 和 B 的兼容"

### 1.2 其余内容类型

| 文件夹 | 放什么 |
|---|---|
| `内容拓展/动物` | 普通动物、宠物、坐骑（非种族化的） |
| `内容拓展/植物` | 作物、树木、采集物 |
| `内容拓展/基因` | 纯基因拓展，不构成新种族 |
| `内容拓展/家具` | 家具、装饰、照明 |
| `内容拓展/发型` | 发型包 |
| `内容拓展/服装` | 服装、护甲（非种族专属） |
| `内容拓展/地面` | 地板、地形贴图 |
| `内容拓展/武器` | 武器、弹药 |
| `内容拓展/建筑` | 生产、电力、存储、防御等建筑 |
| `内容拓展/派系` | 派系、据点、贸易 |
| `内容拓展/事件` | 任务、事件、袭击 |
| `内容拓展/场景` | 开局剧本（Scenario） |
| `内容拓展/特性` | 特质、背景故事、能力 |
| `内容拓展/玩法` | 规则调整、作弊向、难度改动 |
| `内容拓展/音乐` | 背景音乐、音效包 |
| `内容拓展/生物` | 机械族、虫族、异常体等非人形生物 |
| `内容拓展/地图` | 地形生成、世界地图、生物群系 |
| `内容拓展/食物` | 食物、烹饪、饮品 |
| `内容拓展/医疗` | 手术、药物、义体 |
| `内容拓展/载具` | 载具及其框架内容 |
| `内容拓展/生产` | 工作台、配方、材料加工 |
| `内容拓展/研究` | 科技树、研究项目 |

以上是起手清单，缺什么直接加新文件夹，命名用两到四个字的中文名词。

**优先级**：先看是不是种族（含二次元动物）；是就进 `种族/<种族名>`；不是再按上表选最贴近的一项。一个模组只进一个分类。

## 2. 非内容拓展

**不增加游戏内容**、只改变体验或表现的模组。

| 文件夹 | 放什么 | 例子 |
|---|---|---|
| `非内容拓展/性能优化` | 提升帧数、降低卡顿、减少内存 | Performance Mod、Toggleable Overlay |
| `非内容拓展/UI 美化` | 界面外观、图标、字体、配色 | 各类 UI 重绘 |
| `非内容拓展/内容简化` | 去掉游戏里已有内容 | No zzz、No shadow、No filth |
| `非内容拓展/贴图美化` | 只换皮/重绘，不改数值，也不是界面 | 机械体重绘、动物换皮 |
| `非内容拓展/文本修改` | 改名、改描述、修正文案 | 把“智人种”改成“原始种” |
| `非内容拓展/操作便利` | 快捷键、批量操作、信息面板（增加的是操作效率，不是新内容） | 各种 QoL |
| `非内容拓展/汉化工具` | 与具体内容无关的翻译框架/工具 | 翻译器、字体替换工具 |

判断分歧时：**改变"能看到/能操作什么"→ 内容拓展；只改变"顺不顺手/好不好看/快不快"→ 非内容拓展。**

---

## 3. 系列

**只有内容混杂的整合系列才放这里**——一个系列里同时包含种族、建筑、武器、事件等多种内容，无法归入单一内容类型。

```
系列/Vanilla Expanded
系列/Medieval Overhaul
```

规则：

- 属于某个综合系列的模组，**整组归该系列**，即使单个模组只加了一种内容（例如某个 VE 子模组只加家具，也放 `系列/Vanilla Expanded`）
- 单一内容的合集（例如一套纯发型包、一套纯家具包）**不放这里**，仍进对应内容类型
- 系列的判定看"发行系列"，不看单个模组的内容

---

## 4. 判定顺序

```
该模组属于某个综合系列？
  是 → 系列/<系列名>
  否 → 它定义/服务于某个种族？
          是 → 内容拓展/种族/<种族名>（多族用 and 连接）
          否 → 它增加游戏内容？
                  是 → 内容拓展/<最贴近的内容类型>
                  否 → 非内容拓展/<性能优化|UI 美化|内容简化|...>
```

---

## 5. 命名约定

- 路径层级固定三段以内：`顶层/子类` 或 `顶层/子类/名字`
- 种族和系列用英文原名，与模组本体一致，方便对照
- 内容类型用中文短词
- 多族合并文件夹：`A and B`、`A and B and……`
- 大小写不敏感，但按原模组写法填
